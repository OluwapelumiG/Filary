One focused form. One trigger. Done.

Filary finds the form you are in, reads field names and types, asks the generator for values, and fills only that form — nothing else on the page.

  1. 01 Focus a field Inside any standard HTML form. Named controls are what Filary sees.
  2. 02 Trigger Filary Toolbar popup, ⌘⇧Y / ⌥⇧F, or a shortcut you set in Chrome.
  3. 03 Get real-looking data Locale, email domains, fill mode, and passwords — your rules.

Built for the forms you actually test

Fake data that looks fake slows everyone down. Filary generates values that match the field — text, email, radio, checkbox — so signup flows, checkout, and admin screens feel ready to ship.

  • Scoped fill Only the owning form is filled. Sibling forms and stray inputs stay untouched.
  • Type-aware Field types travel with the request, so radios, checkboxes, and text get values that fit.
  • Hosted API Works against Filary’s Vercel API out of the box, or point the extension at your local generator.

Locale-aware, not Lorem Ipsum

Names, phones, cities, and states follow the locale you choose. Country stays fixed per locale so the whole address reads as one place.

You set the rules

Defaults that get out of the way — and levers when you need them.

Fill mode
Empty fields only, or overwrite matched fields when retesting.
Locale
Start with Nigeria (English). Names and places stay coherent.
Email domains
gmail.com, yahoo.com, outlook.com — or your own list.
Passwords
Off by default. Opt in with a default password when you need it.
Server URL
Hosted Filary API, or localhost while you develop.
Shortcuts
⌘⇧Y and ⌥⇧F on macOS — edit anytime in Chrome’s shortcut panel.
