Filary

Settings

Configure the local server, keyboard shortcut, and fill behavior. Filary fills the form that owns the focused input.

Server

Default is http://localhost:7002/api. Start it with bun run server. Fill uses POST /generate.

Keyboard shortcut

Current: …

Both shortcuts are registered (⌘⇧Y / Ctrl+Shift+Y and ⌥⇧F / Alt+Shift+F). Change them on Chrome’s Extensions shortcuts page.

Fill behavior

Locale drives names, phone, city, and state. Country is fixed for known locales (e.g. Nigeria). Emails use a random domain from your list. Sent to POST /generate on each fill.
